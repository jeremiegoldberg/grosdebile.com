# Contribuer à grosdebile.com

Bienvenue ! Le projet est volontairement ouvert : le site peut devenir un jeu, un outil absurde, une œuvre collective ou tout autre chose. Les propositions concrètes sont particulièrement utiles.

## Proposer une idée

1. Consulte les issues ouvertes pour voir si l’idée existe déjà.
2. Ouvre une issue avec le modèle **Proposer une idée**.
3. Décris le principe, ce qui le rend amusant ou intéressant, et une première manière de le réaliser.

## Envoyer du code

1. Forke le dépôt et crée une branche dédiée.
2. Fais des changements ciblés et faciles à tester.
3. Vérifie le rendu dans un navigateur récent, sur ordinateur et mobile.
4. Ouvre une pull request en expliquant le problème ou l’idée, les changements effectués et comment les tester.

Pour la première version, le site est statique : HTML, CSS et JavaScript sans compilation.

## Quelques principes

- Préfère une idée simple et un prototype fonctionnel à une grosse réécriture prématurée.
- Garde le site utilisable sur mobile et respecte les préférences de réduction des animations.
- Évite les dépendances inutiles et explique celles que tu ajoutes.
- N’ajoute jamais de secrets, de données personnelles ou de code malveillant.
- Respecte les autres contributeurs et les droits d’auteur.

## Licence et publication

La licence du projet reste à définir. En attendant qu’elle soit clarifiée, n’envoie que des contributions que tu es autorisé à proposer et ne présume pas d’une licence de réutilisation. Les contributions fusionnées et la mise en production restent soumises à validation par le propriétaire du projet.
