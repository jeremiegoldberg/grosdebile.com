# grosdebile.com

Un domaine, une page blanche, une idée collective.

Le but de ce dépôt est de permettre à n’importe qui de proposer, via une issue ou une pull request, ce que pourrait devenir [grosdebile.com](https://grosdebile.com). Le projet final n’est pas décidé : il sera imaginé avec la communauté.

## Le premier prototype

Cette première version est une landing page statique en HTML, CSS et JavaScript, sans framework ni étape de compilation.

Pour la tester localement, ouvre simplement `index.html` dans un navigateur. Les polices sont chargées depuis Google Fonts ; le reste fonctionne sans dépendance JavaScript externe.

## Idées possibles

Un jeu absurde, un générateur inutile mais indispensable, une œuvre collective, un petit service web ou une idée encore jamais proposée. Toutes les propositions originales et réalisables sont les bienvenues.

## Participer

- Ouvre une issue pour proposer une idée.
- Commente les propositions existantes.
- Soumets une pull request avec un prototype, du code ou de la documentation.
- Explique ta contribution et reste ouvert aux retours.

Consulte [CONTRIBUTING.md](CONTRIBUTING.md) avant de contribuer.

## Règles

- Sois respectueux : pas de harcèlement ni de discrimination.
- Respecte la loi, la vie privée et les droits d’auteur.
- Ne publie pas de secrets, mots de passe ou données personnelles.

## Gouvernance

Le projet est ouvert aux propositions de tous. Le propriétaire du domaine conserve la décision finale sur les contributions fusionnées et la mise en production. Une pull request est une proposition, pas une garantie de publication.
